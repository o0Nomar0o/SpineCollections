### 📂 Repository Structure
The data is organized by game title. Each folder typically contains:
* `.skel` or `.json` (Skeleton Data)
* `.atlas` (Texture Atlas)
* `.png` (Texture Sheets)

These files are provided for personal study of Spine/Live2D runtimes. By using these files, you agree not to use them in any commercial products or infringing projects.
